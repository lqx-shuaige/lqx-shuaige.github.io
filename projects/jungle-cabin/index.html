林间栖所

雨林、溪流与一间亮着暖灯的木屋，可以切换昼夜和雾气，也可以走进屋内参观。

已归档 Web 3Dthree.js提示词

支持环绕观景、人物跟随和第一人称步行。沿石径走上木阶，可以近看客厅、书桌和卧榻；手机上用摇杆移动、拖动转头。场景和依赖打包在单个 HTML 内，可以离线打开。下方保留了最初的制作提示词，可展开阅读或整份复制。

进入小屋

请用支持 WebGL 2 的 Chrome 或 Edge 打开。WASD 移动、V 切换视角；卡顿时点右上角「？」切换流畅画质。
