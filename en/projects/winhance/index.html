Winhance

A tuning panel for Windows 10 / 11 — strip the preloads, flip off the privacy and background switches you do not want, rebuild the taskbar, Start menu and power plan the way you like them.

Resources WindowsTuning

One switch per setting with a line of explanation — no one-click "boost" theatre — and the list is searchable when a name is unfamiliar. Whatever you have switched can be saved into a config file and imported again after a reinstall or on another machine. The official installer ships both an installable and a portable build. The author states the tool is still in development; file an issue in the repository when something breaks.
