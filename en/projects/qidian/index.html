CAT 09 / 15 · Windows

QiDian

Every app on a Windows machine gathered into a categorised launcher, with a reversible check-up and tuning kit and a fully offline local assistant beside it.

Archived WindowsSystem tool

The backend is Tauri 2 + Rust and the interface is hand-written TypeScript. On launch it scans Start-menu, desktop and taskbar shortcuts, the uninstall registry, App Paths, shell:AppsFolder and Microsoft Store apps, then lays them out by category — development, office, design, media and so on. Categories are editable and sorting switches between name, recently used and most used. Search weights names, compact names, initials, pinyin (full and first letters), publisher, category and install path, with a fuzzy fallback for a misspelt word. Appearance comes in five styles (Win11, Miuix, macOS, Mono, custom), twelve palettes, eight accent colours and a local wallpaper library, and a whole look can be saved as “My theme”. The toolbox beside it covers check-up, tuning, memory, background, app management and startup/tray: each of the 51 registry policies is backed up before it is written and read back afterwards, so anything can be undone; there are 27 cleanup locations, one-click public DNS switching and the hidden Ultimate Performance power plan, plus a sweep for leftovers in install folders after an uninstall. Since v2.0 there is an optional local AI assistant: three Qwen2.5 models plus Whisper speech recognition, fully offline once the components are downloaded, able to search, launch and close apps, read memory, commit memory and battery, free memory, open web pages and switch between light and dark; tool permissions come in two levels and the whitelist has no shell and no file deletion. Everything stays on the machine — no network calls, no ads, no resident background process — and the source is MIT-licensed.
