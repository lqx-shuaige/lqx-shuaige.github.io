这是一篇示例文章，用来验证博客链路是否通畅：Markdown 会自动出现在列表页、生成详情页、进入 RSS 与站点地图，并能被标题/标签搜到。

为什么是 Astro

写文章只需要往 src/content/blog/ 里丢一个 .md 文件，其余都是构建时生成的。它默认不往浏览器塞框架运行时，页面打开就是静态 HTML + 一小段脚本。

// 文章元信息写在文件头，列表和 RSS 都从这里读
export const data = { title: '标题', date: 2026-09-18, tags: ['建站'] };

不想要这篇就删掉这个文件，站点会自动少一条。
